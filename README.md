# RaabtaAI-PSL

Pose extraction and Pakistani Sign Language (PSL) work for **Raabta AI**, a final-year project at NUST that translates sign language into text and audio.

The main recognition model lives in the `RaabtaAI` repository. This repository holds the steps that prepare PSL, ArSL and Isharah data for it.

## Branches

| Branch | Contents |
| --- | --- |
| `main` | this overview |
| `pose-extraction` | one MediaPipe pose extraction for Isharah, ArSL and PSL, with calibrated hand recovery, per-signer quality gates and a Kaggle notebook (`notebooks/pose_extraction.ipynb`) |

See the README on each branch for its details.
